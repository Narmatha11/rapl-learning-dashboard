# WordPress Challenge

## Objective

The objective is to create a responsive RapL Genie page in WordPress while making sure that the implementation is safe and maintainable.

## My Approach

I would create the RapL Genie page using the existing WordPress setup and its approved theme or page-building tools.

I would avoid modifying WordPress core files because core changes can be overwritten during WordPress updates.
